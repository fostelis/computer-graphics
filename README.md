# Алгоритм Брезенхема и заливка

Проект состоит из двух файлов:

* `Bresenham.py` — построение отрезка по алгоритму Брезенхема;
* `Brush.py` — рисование замкнутых контуров и их заливка выбранным цветом.

Обе программы имеют графический интерфейс, созданный с помощью библиотеки Pygame.

## Используемые библиотеки

* `pygame` — создание окна, обработка нажатий мыши и клавиатуры, отрисовка сетки и элементов интерфейса;
* `sys` — завершение работы программы.

Для установки Pygame:

```bash
pip install pygame
```

## Алгоритм Брезенхема

Файл `Bresenham.py` позволяет ввести координаты начала и конца отрезка и построить его на координатной плоскости.

Алгоритм Брезенхема определяет, какие клетки сетки нужно закрасить, чтобы получить приближённое изображение прямой линии. На каждом шаге вычисляется ошибка, по которой выбирается следующее направление движения по осям `x` и `y`.

Алгоритм работает только с целыми числами и не требует вычислений с плавающей точкой.

Колёсико мыши используется для изменения масштаба координатной плоскости.

## Заливка с затравкой

Файл `Brush.py` представляет собой простой редактор с клетчатым полем.

В режиме рисования можно выбрать цвет и создать контур. В режиме заливки выбранная область закрашивается с помощью алгоритма заливки с затравкой.

Алгоритм начинает работу с клетки, на которую нажал пользователь. Затем он проверяет соседние клетки в четырёх направлениях:

* вправо;
* влево;
* вверх;
* вниз.

Если соседняя клетка имеет цвет исходной области, она также добавляется в заливку. Работа продолжается, пока не будет закрашена вся связанная область.

Контур должен быть замкнутым. Если в нём есть разрыв, заливка выйдет за его границы.

Для хранения клеток, которые ещё нужно обработать, используется стек. Это позволяет избежать переполнения рекурсии при заливке больших областей.

## Запуск

Запуск построения линии:

```bash
python Bresenham.py
```

Запуск редактора с заливкой:

```bash
python Brush.py
```
